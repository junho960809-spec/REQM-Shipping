# 29CM Chrome 확장 연동

REQM 프로그램은 로그인 쿠키를 읽거나 Chrome을 직접 실행하지 않는다. 작업자가 `REQM_CS` Chrome 프로필에서 로그인한 29CM 탭에 REQM 확장 프로그램을 설치한다.

확장 프로그램은 해당 탭에서만 상품·옵션 목록을 읽고 로컬 REQM 브리지(`127.0.0.1`)로 보낸다. 품절/판매 재개는 사용자가 REQM에서 승인한 요청만 확장 프로그램이 해당 탭에서 실행하도록 한다.

따라서 기존 CS 업무 탭을 유지하면서도 Chrome 세션 복사나 별도 재로그인이 필요 없다. 실제 설치 전에는 Chrome 확장 프로그램 개발자 모드 로드 및 로컬 브리지 서버를 함께 배포해야 한다.
